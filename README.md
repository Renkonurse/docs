# 📚 Documentación completa — RenCoNurse CriticalCare

Documentación **ampliada y basada en la evidencia** de la app **RenCoNurse CriticalCare** (enfermería de cuidados intensivos).

Cada pantalla de la app enlaza aquí con su documento completo y, cuando existe, con el vídeo oficial.

**Web:** https://renkonurse.github.io/docs/

> **Uso seguro:** esta biblioteca es material educativo de apoyo, no una prescripción ni un sustituto del juicio clínico. Contrasta dosis, umbrales y procedimientos con la ficha técnica, la guía vigente y el protocolo local antes de aplicarlos. Las recomendaciones pueden variar según población, dispositivo y contexto.

La documentación web utiliza una estructura de lectura común —títulos jerárquicos, secciones escaneables, avisos y fuentes identificables— y acentos de color por familia temática. Las fuentes y la fecha de actualización deben comprobarse en cada guía; la apariencia común no implica que todos los contenidos se hayan revisado simultáneamente.
